# vesta_space_filling

구조를 **눈으로 확인**해야 할 때 쓴다. 계산 결과가 이상한지(흡착종이 슬랩에 박혔는지, TS 가 엉뚱한 자리인지, 분자가 PBC 로 잘렸는지)는 숫자만으론 안 보인다.

## 쓰는 법

```bash
python ~/.claude/skills/vesta_space_filling/scripts/make_vesta.py <파일 또는 폴더>
```

| 인자 | 뜻 |
|---|---|
| `<파일 또는 폴더>` | 폴더면 하위 구조파일 **전부** (`.vasp .cif .xyz .extxyz .traj .cfg` / `POSCAR` `CONTCAR`) |
| `[출력폴더]` | 생략하면 입력 옆 `VESTA/` |
| `--norep` | 원셀 그대로 (기본은 2×2×1 슈퍼셀) |
| `--rep 3x3x1` | 슈퍼셀 직접 지정 |
| `--all-bonds` | 금속–금속·동일원소 쌍도 결합선으로 그린다 (기본은 안 그림) |

```bash
# 한 개
python .../make_vesta.py relaxed.vasp
# 폴더 전부, 원셀로
python .../make_vesta.py ./structures ./VIEW --norep
```

## 왜 2×2×1 이 기본인가
슬랩 셀을 원셀로 열면 **PBC 경계에 걸친 흡착 분자가 반으로 잘려** 보인다. 2×2 로 깔면 온전한 분자가 한 번은 나와 판정이 된다. 슈퍼셀은 **.vesta 파일에만** 적용되고 계산과 무관하다.

## 원소 지정 — 주기율표가 **파일 안에 다 박혀 있다**

`scripts/make_vesta.py` 의 `ELEM` 에 **H~Lr 103종 전부** `(반지름 Å, (R,G,B))` 로 들어 있다.
런타임에 만들지 않으므로 **파일만 열면 어떤 원소가 무슨 색·크기로 나올지 다 보인다.**

- **35종은 연구실 확정값** — O·C·H·N·Ni·Pt·Ce·La 는 DRM 확정, Cu·Zn·Zr·In 등은 서로 안 겹치게 고른 값.
  예전 그림과 색이 같아야 하므로 **이 값들은 바꾸지 말 것.**
- **나머지 68종은 Jmol 표준색 + 공유결합반지름**으로 미리 채워 넣었다. 마음에 안 들면 그 줄만 고친다.
- 표에 없는 기호가 오면 자홍색 폴백 + 경고 한 줄. 죽지 않는다.

**결합**은 확정 규칙(`BONDS`) 우선, 없는 쌍은 `d_max = 1.35 × (r_i + r_j)`.
**금속–금속·동일원소 쌍은 기본적으로 안 그린다** — space-filling 에서 거미줄이 되어 아무것도 안 보인다 (`--all-bonds` 로 켬).

## 템플릿
`scripts/vesta_template.vesta` (= DRM `img03.vesta` 에서 **구조 데이터를 걷어낸 3 KB 껍데기**).
원본은 750원자 구조가 통째로 들어 있어 177 KB 였는데, 그 부분은 어차피 매번 교체되므로 버렸다
(출력은 바이트 단위로 동일함을 확인). **구조 의존 섹션만** 교체한다 —
`TITLE / CELLP / STRUC / THERI / SBOND / SITET / ATOMT`.
`STYLE`(`MODEL 1` = space-filling)·조명·카메라·배경은 템플릿 그대로 두므로 열면 항상 같은 룩이다.

## 주의
- 출력은 **보기 전용**이다. `.vesta` 를 다시 계산 입력으로 쓰지 말 것 (슈퍼셀이 들어가 있다).
- `.traj` 는 **마지막 프레임**만 쓴다 (`index=-1`).
- 변환 실패한 파일은 건너뛰고 이유를 출력한다 — 전체가 죽지 않는다.
